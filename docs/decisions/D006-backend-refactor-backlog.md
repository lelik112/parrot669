# D006 — приоритет оставшихся backend extraction этапов

**Decision:** оставить оставшиеся route extraction задачи в LATER и выполнять их отдельными этапами после календарного PM-001. Предлагаемый порядок: auth routes; внешние calendar lifecycle операции после сверки с PM-001; legacy verification challenges после определения совместимости с его сохранённым flow.

**Problem:** после рефакторинга остались технические кандидаты в общих route/service/repository файлах. Переносы могут пересечься с активной продуктовой задачей PM-001.

**Reason:** текущая цель MVP — доказать полезность доступности и контакт, а не завершить архитектурное разбиение. Сохранение поведения и последовательный scope снижают риск конфликтов; календарные и legacy изменения особенно зависят от принятого PM-001 контракта. Каждый этап можно активировать позже при конкретном приоритете и исполнителе.

**Alternatives:** выполнять все переносы прямо сейчас; объединить calendar sync и challenges с PM-001; оставить предложение только в свободном чате.

**Rejected:** брать техническое улучшение в NOW без подтверждённой продуктовой причины; смешивать механический перенос с PM-001 или менять/удалять legacy endpoints без отдельного решения.

**Date:** 2026-09-24.
