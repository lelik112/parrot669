## Requirements

- Борис связывает наблюдения с PM-007, а для адреса, календаря и переписки — с PM-004, PM-001 и PM-003 соответственно.

## Acceptance criteria
- [ ] Видны реальные touch, клавиатура и date picker в указанной мобильной среде.
- [ ] Результаты основных путей с evidence внесены в PM-007; неподтверждённые платформы остаются открытыми.
